# @vyro/mobile

Expo SDK 57 app for iOS and Android. Shares types, validation, the API client and design tokens with the web app.

```bash
cp .env.example .env
pnpm start      # Expo dev server
pnpm test       # Jest
pnpm export     # iOS + Android bundles
```
See ENVIRONMENT_SETUP.md at the repo root for variables, and FEATURE_TRACKER.md for status.
